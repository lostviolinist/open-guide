# Source provenance

OpenGuide starts from the MIT-licensed public https://github.com/farzaa/clicky repository at commit e71105ce091d71dff4d89cf5d8d37ea1df460961 (retrieved 2026-11-06).

The original LICENSE is retained. The original Xcode project, sources, and worker remain available as the legacy foundation. The OpenGuide Swift package is the actively developed MVP. Its ScreenCaptureService adapts the public CompanionScreenCaptureUtility's ScreenCaptureKit filtering and display coordinate mapping. Other new Sources files implement OpenGuide's own protocol, host, and playback.

A fresh source history was used because GitHub push protection identified a credential in an older upstream commit. That history is not published here. No recovered proprietary application code, prompts, private service configuration, or reverse-engineering report is included.

OpenGuide is independent and is not affiliated with or endorsed by HeyClicky.
